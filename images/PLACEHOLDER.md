# Chrome Web Store Submission

This folder contains assets required for Chrome Web Store submission.

## Required Icons

Place the following PNG files in this folder:

| File | Size | Purpose |
|------|------|---------|
| `icon16.png` | 16x16 | Toolbar favicon |
| `icon32.png` | 32x32 | Retina toolbar |
| `icon48.png` | 48x48 | Extension manager |
| `icon128.png` | 128x128 | Store listing + installer |
| `promo-icon.png` | 128x128 | Promotional (separate) |

## Screenshots (Optional but Recommended)

| File | Size |
|------|------|
| `screenshot1.png` | 1280x800 or 640x400 |
| `screenshot2.png` | 1280x800 or 640x400 |

## How to Generate Icons

1. Design a 128x128px icon in your favorite editor
2. Export as PNG at required sizes
3. Or use online tools like:
   - https://www.chromeapps.iconator.com/
   - https://app-ico.github.io/

## Store Listing Tips

- **Short description**: Max 132 characters
- **Detailed description**: Explain key features
- **Category**: Productivity or Utilities
- Enable "Chrome Web Store" visibility
